SKYRIM GRIMOIRE NORDIQUE V4

Version 100 % autonome : UN SEUL FICHIER index.html.
Aucun dossier data. Aucun fichier JavaScript externe. Aucun service worker.

Pour GitHub Pages :
1. Supprimer les anciens fichiers du dépôt.
2. Envoyer uniquement index.html à la racine.
3. Settings > Pages > Deploy from branch > main > /(root).
4. Recharger l'adresse GitHub Pages.
5. Si Safari affiche encore l'ancienne page, ouvrir une fois l'adresse en navigation privée puis revenir sur la page normale.
